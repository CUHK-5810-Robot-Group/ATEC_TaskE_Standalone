# 视频复盘与第二周改动

视频显示原流程按预设 TCP 位姿接近物体，再通过时间推进到闭合和搬运。这个流程在一次固定摆放中可以成功，但它没有回答两个关键问题：夹爪是否压在瓶身中部，以及物体换位置后闭合方向是否仍然正确。

## 观察到的风险

1. 芥末瓶靠近瓶口或肩部时，接触点的有效支撑长度变短，抬升后容易绕夹爪转动或滑落。
2. 固定姿态没有利用轮廓的窄边，糖盒和香蕉换一个平面方向后，指尖可能只碰到边角。
3. 只按时间进入下一个阶段，无法区分空抓、抬升滑脱和篮内释放失败。
4. 控制频率高于相机更新频率，旧目标如果没有时效门控，机械臂会继续追逐已经失效的位姿。

## 代码对应关系

- 主轴中间 50%：减少瓶盖、瓶肩和香蕉尖端对抓取中心的影响。
- PCA minor axis：让夹爪沿观测到的窄边闭合；直立瓶对应水平横向夹取。
- 深度 10--90% 裁剪和中位数：降低桌面背景与单点深度错误的影响。
- `TemporalPoseFilter`：限制目标跳变，超过阈值时保持动作。
- `GraspStateMachine`：抬升后检查物体随动，失败进入有界重试，并重新感知后回到 approach。
- `compare_strategies.py`：只比较同一 seed 集合和同一终止定义下的方案 A/B。
