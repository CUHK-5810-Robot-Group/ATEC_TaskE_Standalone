# Task E 视频复盘

本地两段视频均为 640×480、50 FPS，画面展示了糖盒、芥末瓶和香蕉依次抓放到篮子的流程。它们对改进的价值在于暴露接触策略，而不是证明一次成功就能覆盖随机位置。

## 观察

- 现有动作是“先到预设位姿，再闭合夹爪”，没有从物体轮廓重新计算闭合方向。对盒体和香蕉，姿态变化会让指尖接触边缘；对瓶子，瓶口或瓶肩附近的接触点会产生旋转和滑脱。
- 瓶子的稳定约束应写成“瓶身高度中部 + 横向窄边”，而不是“沿用上一次的 TCP 四元数”。如果目标换一个桌面位置，固定姿态仍可能碰到瓶身，但夹力方向和力矩不再合适。
- 连续三件物体的流程需要在每件物体释放后重新感知。仅凭动作时间推进到下一个目标无法区分空抓、抬升滑脱和篮内放置失败。
- 视频帧率明显高于腕部相机的 10 Hz 更新配置；控制器应在新 RGB-D 帧到达时更新目标，50 Hz 控制步骤之间复用带时效限制的姿态，而不是假设每个控制步有新图像。

## 对应修改

`demo/oywc_rgbd_grasp.py` 中的 `CenterlineNarrowEdgeGraspPlanner` 使用 mask 的 PCA 主轴和次轴，深度只取有效像素的稳健中位数；对 `mustard_bottle` 明确取主轴中间 50%，让瓶身中部成为抓取点。`TemporalPoseFilter` 和 `GraspStateMachine` 分别负责跳变门控和有限重试。

这份复盘没有把视频中的单次结果当作 18 分证明。完整分数仍需要在评分系统提供的独立 seed 上按同一终止条件实测，并提交每个 episode 的成功/失败证据。
